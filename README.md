# everyhandbook.github.io

김태형(모두의 핸드북)의 개인 사이트입니다.

- `/` 첫 화면: 소개, 의뢰 안내, 만든 것들, 채널, 연락처 (`index.html`, `support.js`가 화면을 그립니다)
- `/card` 디지털 명함: 의뢰를 생각하는 분이 처음 보는 화면 (`card/index.html`, 외부 파일 없이 한 장)

## 고치는 방법

2026-11-27부터 이 레포가 원본입니다. 예전에는 디자인 도구에서 내보낸 파일을 그대로 올렸는데, 지금은 이 레포의 html을 직접 고치고 PR로 올립니다. 예전 내보내기 파일로 덮어쓰면 그 뒤의 수정이 사라지니 덮어쓰지 않습니다.

`main`에 합쳐지면 GitHub Pages가 1분 안쪽으로 자동 배포합니다.

## 올리지 않는 것

공개 레포입니다. 전화번호, 개인 메일, 회사 이름과 발주처, 지명이 보이는 작업 화면은 올리지 않습니다. 강의 평점과 수강생 수처럼 바뀌는 숫자에는 기준 시점을 함께 적습니다.
